# English–Swahili Parallel Dataset

## Overview

This repository contains a parallel English–Swahili dataset intended for machine translation, natural language processing (NLP), language modeling, and linguistic research. The dataset consists of paired English sentences and their corresponding Swahili translations.

### Dataset Statistics

* **File:** `ensw.csv`
* **Format:** CSV
* **Columns:**

  * `English sentence`
  * `Swahili Translation`
* **Approximate Number of Sentence Pairs:** 210,471

## About the Swahili Language

### Where Swahili Is Spoken

Swahili (Kiswahili) is a Bantu language spoken primarily in East and Central Africa. It serves as a national or official language in several countries, including:

* Kenya
* Tanzania
* Uganda
* Democratic Republic of the Congo (DRC)
* Rwanda
* Burundi
* Mozambique (some regions)
* Comoros

Swahili is also widely used as a regional lingua franca across East Africa.

### Number of Speakers

Swahili is one of the most widely spoken African languages, with an estimated **100–200 million speakers**, including both native and second-language speakers. Most speakers use Swahili as a second language for communication across different ethnic and linguistic groups.

### Interesting Linguistic Features

#### 1. Noun Class System

Swahili uses an extensive noun class system rather than grammatical gender. Nouns are grouped into classes, and verbs, adjectives, and pronouns agree with the noun class.

Example:

* *mtoto mzuri* — "good child"
* *watoto wazuri* — "good children"

#### 2. Agglutinative Morphology

Swahili words often contain multiple grammatical elements within a single word.

Example:

* *Nitakupenda*

  * *Ni-* = I
  * *-ta-* = future tense
  * *-ku-* = you
  * *-penda* = love

Meaning: **"I will love you."**

#### 3. Phonetic Orthography

Swahili spelling is highly phonetic, meaning words are generally pronounced as they are written. This makes reading and pronunciation relatively straightforward compared to many other languages.

#### 4. Arabic Influence

Due to centuries of trade along the East African coast, Swahili contains many loanwords from Arabic.

Examples:

* *kitabu* (book)
* *safari* (journey)
* *habari* (news/information)

#### 5. Latin Script

Modern Swahili is written using the Latin alphabet and does not use tone marks in standard orthography.
