# English → Kiswahili

## About this language

**Language name:** Kiswahili (Standard/Sanifu)
**Also known as:** Swahili
**Region(s) spoken:** Kenya, Tanzania, Uganda, Rwanda, DRC, Burundi, Mozambique and across East and Central Africa
**Approximate number of speakers:** 200+ million (native and second language speakers)
**Language family:** Bantu (Niger-Congo)
**Writing system / script:** Latin alphabet, left to right

---

## Why this language needs machine translation

Kiswahili is one of Africa's most widely spoken languages and serves as a
lingua franca across East and Central Africa. Despite its reach, it remains
significantly underserved by mainstream AI translation tools. Communities
that rely on Kiswahili for education, healthcare, commerce and government
communication have little access to quality automated translation. Adding
Kiswahili to La Lango AI directly serves over 200 million people.

## Dataset

**Source of the parallel corpus:** Global Voices (globalvoices.org), obtained via OPUS
**Corpus size:** 5,000 sentence pairs
**Domains covered:** News, citizen media, human rights, technology, civic reporting
**License:** CC BY 3.0 — https://creativecommons.org/licenses/by/3.0/

**File:** `languages/english-kiswahili/english-kiswahili-data.csv`
**Format:** UTF-8 CSV with a header row, following the team's two-column
format (see `sample_data.csv`). Fields are quoted only where they contain a
comma or quote mark.
**Columns:** `english`, `kiswahili`
**Casing:** all text is lowercased, matching the team sample. The original
casing can be regenerated by running the build script below without
`--lowercase`.

### Attribution

This dataset contains text from Global Voices (https://globalvoices.org),
used under the Creative Commons Attribution 3.0 license. Global Voices
articles are translated by volunteer translators of the Lingua project,
so the corpus is human-translated rather than machine-generated.

The parallel corpus was obtained through OPUS
(https://opus.nlpl.eu/GlobalVoices/), which aligns the original articles at
sentence level.

### How this file was produced

The raw corpus contains 32,307 aligned pairs. These were filtered and then
randomly sampled down to 5,000 using `backend/scripts/build_globalvoices_csv.py`
with a fixed seed, so the result is reproducible:

```
python backend/scripts/build_globalvoices_csv.py \
  --en GlobalVoices.en-sw.en --sw GlobalVoices.en-sw.sw \
  --target 5000 --seed 42 --lowercase \
  --out languages/english-kiswahili/english-kiswahili-data.csv
```

Filtering removed:

| Reason | Pairs |
|---|---|
| Blank on one side | 1,525 |
| Under 3 words | 1,086 |
| Over 50 words | 796 |
| Length ratio above 2.0 | 372 |
| Identical on both sides | 186 |
| Duplicate English sentence | 255 |

28,087 pairs survived; 5,000 were sampled from those.

### A note on the previous QED recipe

Earlier revisions of this README documented a 3,000-pair subset of the QED
corpus. That source has been retired here: QED is distributed by QCRI for
research purposes only, so its text cannot be committed to an MIT-licensed
repository. Global Voices (CC BY 3.0) permits redistribution with attribution,
which is why it was chosen instead.

### Preprocessing

`preprocess.py` reads two plain-text files (one sentence per line), not CSV,
so preparing this dataset for training is a two-step process.

**Step 1 — convert the CSV into `.src` / `.tgt` files:**

```
python backend/scripts/csv_to_parallel.py \
  --csv languages/english-kiswahili/english-kiswahili-data.csv \
  --output data/raw/english-kiswahili/
```

This writes `all.src` (English) and `all.tgt` (Kiswahili), line-aligned —
line N of one file is the translation of line N of the other.

**Step 2 — clean and split into train/val/test (80/10/10):**

```
# Windows
$env:PYTHONPATH="backend"
python backend/scripts/preprocess.py --src data/raw/english-kiswahili/all.src --tgt data/raw/english-kiswahili/all.tgt --output data/processed/english-kiswahili/

# Linux/Mac
PYTHONPATH=backend python backend/scripts/preprocess.py --src data/raw/english-kiswahili/all.src --tgt data/raw/english-kiswahili/all.tgt --output data/processed/english-kiswahili/
```

Expected result: `preprocess.py` applies its own cleaning (default
`--max-length` is 200 characters), which removes a further 769 pairs from the
5,000. The final split is 3,384 train / 423 val / 424 test.

Note: `data/raw/` and `data/processed/` are gitignored, so the files generated
by these two steps stay on your machine. If `preprocess.py` gains native CSV
support, step 1 becomes unnecessary.

## Linguistic notes for contributors

- Kiswahili uses spaces between words - tokenization is straightforward
- No tone marks or diacritics that affect meaning
- Language is agglutinative - verb roots take many prefixes and suffixes
  Example: "Nitakupenda" = "I will love you" (ni-ta-ku-penda)
- Standard Kiswahili (Sanifu) has consistent spelling - minimal variation
- This dataset covers Standard Kiswahili only, not Sheng or coastal dialects
- Noun class system - nouns belong to classes that affect agreement

## Known issues / limitations

- Domain is skewed towards news and civic reporting, since Global Voices is a
  citizen-media publication. Everyday conversational register is
  underrepresented.
- Because the file is lowercased, proper nouns (people, places,
  organisations) appear in lowercase.
- Roughly 1-2% of rows retain English proper nouns, publication titles, URLs
  or social-media handles inside the Kiswahili column. These are mostly
  legitimate (for example "The Daily Star" as a newspaper name) but a small
  number are genuine translation artefacts.
- Model not yet trained - Phase 1 implementation in progress
